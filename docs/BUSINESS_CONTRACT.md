## 写入、工具和三场景约束

1. 唯一可变业务字段为发票用途、发票备注。企业、编号、日期、金额、销售方、项目、全部银行记录均不可修改；银行不得新增、删除或修改。不得执行真实记账、付款、报税。（依据：说明“任务范围”后段；规则开篇、R004。）
2. 三场景共用一套处理流程：查询指定企业/月的发票金额、银行收入/支出和规则；按要求补指定发票用途/备注并回查；检查缺用途并承接补充、更新结果。（依据：说明“任务范围”表。）
3. 模型理解并选择查询、追问、工具或结束；不能由关键词、固定场景分支、预设回复冒充模型决策。程序负责计算、参数校验、权限和保存。（依据：说明“基础要求”1、5。）
4. 用户必须明确要求修改，确认企业、发票、修改内容与权限，保存后重新查询；失败说明原因，不误报成功、不重复修改。新开对话不带来修改授权。（依据：说明“基础要求”5、“材料内容和阅读顺序”；规则 R002 2.0。）
5. 保存任务进度及用户明确提出的长期偏好，支持查看、更正、删除，跨会话合理使用，不串用户/企业；每用户每企业最多一个未完成任务。（依据：说明“基础要求”2。）
6. 规则支持导入、查找、更新、停用，注明名称、版本；管理可用 CLI 等简单入口。模型输入只选本轮相关对话、记忆、规则和工具结果，控制长度，保留企业/月/待办，需要当前数据时重查。（依据：说明“基础要求”3、4。）
7. 运行记录可查看本轮模型输入、所选记忆/规则、工具调用和结果，不记录模型密钥。回复直接准确，说明已完成/未完成，仅追问缺失信息，接住补充和更正。（依据：说明“基础要求”6 及其后段。）
8. 自行导入数据、实现查询与保存工具，当前保存数据与原 Excel 分开；流水与发票无对应关系，不能凭同额、相近日期、相同交易方或备注判断已付款。（依据：说明“材料内容和阅读顺序”；数据“说明”A24:A25；规则 R004。）
9. 语言、模型、框架不限；允许简单文本检索、本地存储；不强制网页、向量数据库、多 Agent、复杂运维；不要求图像识别。（依据：说明“基础要求”后段。）

以下命令在仓库根目录执行，只读、不依赖第三方包（在限制临时文件的沙箱中可将代码作为 `python3 -B -c` 参数执行，而不用 here-document）。本轮实际执行的是等价的 `python3 -B -c` 命令，输出 PASS。

```python
from pathlib import Path
from zipfile import ZipFile
import xml.etree.ElementTree as E
from decimal import Decimal as D
from collections import Counter
import hashlib

base = Path('赛题二：财税Harness初赛材料包-v1.1.0')
ns = {'s': 'http://schemas.openxmlformats.org/spreadsheetml/2006/main'}
with ZipFile(base / '02_示例数据.xlsx') as z:
    strings = ([''.join(x.itertext()) for x in E.fromstring(z.read('xl/sharedStrings.xml'))]
               if 'xl/sharedStrings.xml' in z.namelist() else [])
    rel = {x.get('Id'): x.get('Target') for x in E.fromstring(z.read('xl/_rels/workbook.xml.rels'))}
    sheets = {}
    for sh in E.fromstring(z.read('xl/workbook.xml')).find('s:sheets', ns):
        target = rel[sh.get('{http://schemas.openxmlformats.org/officeDocument/2006/relationships}id')]
        root = E.fromstring(z.read(target.lstrip('/') if target.startswith('/') else 'xl/' + target))
        rows = {}
        for row in root.findall('s:sheetData/s:row', ns):
            values = {}
            for cell in row:
                v, typ = cell.find('s:v', ns), cell.get('t')
                value = (strings[int(v.text)] if typ == 's' and v is not None else
                         ''.join(cell.find('s:is', ns).itertext()) if typ == 'inlineStr' else
                         v.text if v is not None else '')
                values[cell.get('r').rstrip('0123456789')] = value
            rows[int(row.get('r'))] = values
        sheets[sh.get('name')] = rows
assert list(sheets) == ['说明', '企业与用户', '发票', '银行流水', '字段说明']
invoices = [sheets['发票'][i] for i in range(6, 46)]
bank = [sheets['银行流水'][i] for i in range(6, 54)]
assert len({(r['A'], r['B']) for r in invoices}) == 40
assert len({(r['A'], r['B']) for r in bank}) == 48
for ent in ['C001', 'C002']:
    for month in ['2026-07', '2026-08', '2026-09']:
        a = [r for r in invoices if r['A'] == ent and r['C'].startswith(month)]
        b = [r for r in bank if r['A'] == ent and r['C'].startswith(month)]
        print(ent, month, len(a), len(b), sum((D(r['F']) for r in a), D(0)),
              {direction: sum((D(r['E']) for r in b if r['D'] == direction), D(0))
               for direction in ['支出', '收入']}, Counter(r['D'] for r in b))
    missing = [r['B'] for r in invoices if r['A'] == ent and r['C'].startswith('2026-09')
               and not r['G'].strip() and (ent == 'C001' or D(r['F']) >= 1000)]
    assert missing == (['F002', 'F004', 'F003', 'F006', 'F009'] if ent == 'C001'
                       else ['F002', 'F005', 'F006'])
    print('required', ent, missing)
for p in sorted(base.iterdir()):
    if p.suffix in ('.docx', '.xlsx'):
        print(p.name, hashlib.sha256(p.read_bytes()).hexdigest())
print('PASS')
```
