模型只做决策。真正读写数据的是工具层，每次调用都在事务内重新校验权限。

证据门：保存只认回读

会计确认后生成一次性授权，后端只执行与确认完全一致的修改，并在同一事务里回读。

模型说「已保存」不算数。没有本轮回读，结果只能是失败。

总结

模型负责理解，程序负责边界和证据，人负责确认。

查询 → 缺口 → 补充/改口 → 审核 → 批准 → 回读 → 复查，每一步都能在界面、数据库、审计或模型输入里核对。
