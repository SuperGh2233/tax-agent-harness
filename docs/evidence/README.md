# 关键运行记录索引

本目录是提交材料「关键运行记录」的入口。所有记录都只用官方 v1.1.0 合成种子、独立临时 SQLite 与 `127.0.0.1` loopback；未使用 `data/harness.db`、真实客户数据或真实密钥；截图不含密钥与个人信息。

## 一、读之前先看：数字口径

缺口数字会随写入变化，同一个库写一次就变一次：

| 时点 | C001 2026-09 缺用途 | 出现在 |
|---|---|---|
| 新建库（未写入） | **5 张**：F002/F004/F003/F006/F009 | DEMO_RERUN、FIXES、本索引 |
| 保存 F002 之后 | **4 张**：F004/F003/F006/F009 | TEST_REPORT 第 6 节浏览器查询 |
| 再保存 F009 之后 | **3 张**：F004/F003/F006 | TEST_REPORT 第 6 节末尾 |

`check_invoice_purpose` 永远返回"库里当时的全量缺用途项"，不做过滤。**任何缺口数字都必须带时点**，否则看起来会自相矛盾。录制演示统一用新建库口径（5 张）。
